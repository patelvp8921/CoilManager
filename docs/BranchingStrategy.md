# Branching Strategy

Use short-lived feature branches for sprint batches and merge through review.

## Branch Naming

- `feature/sprint-1-batch-1-5`
- `fix/<short-description>`
- `chore/<short-description>`

## Guidelines

- Keep commits focused on one task or batch.
- Verify backend and frontend builds before opening a pull request.
- Avoid mixing business-module implementation with foundation work.
