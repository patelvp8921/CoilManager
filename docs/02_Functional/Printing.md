# Slit Coil Label Printing

Slit Coil Labels use a configurable 100 mm × 75 mm thermal layout headed by **Arkon Electricals Private Limited**. Operators can Print Label, Reprint Label, inspect Print History, or Batch Print selected generated coils.

The first print sets Print Count to one. Reprints increment Print Count without changing Label Version. After a material correction, Label Version is explicitly incremented with a required reason. Every print records copies, user, UTC time, optional printer name, print type, and remarks.

Printing uses the browser print dialog. Disable browser headers and footers, set scale to 100%, and select 100 mm × 75 mm media. Direct printer SDK integration, printer discovery, and ZPL are deferred.
